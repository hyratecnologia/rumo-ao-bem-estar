# Rumo ao Bem-Estar

Joguinho em pixel art feito para a **Semana da Psicologia**, sobre saúde mental, cobranças e bem-estar.

**Jogar:** https://hyratecnologia.github.io/rumo-ao-bem-estar/

## A ideia

Você segue uma avenida rumo ao bem-estar. No caminho caem cargas: algumas dá para largar (curtidas, padrão de beleza, "ter mais"), outras não saem (boleto, trabalho, faculdade, doença). As coisas que você ama também caem, e a pressão vai tirando elas de você. Pessoas de máscara de felicidade passam e "chegam lá". O Mercado de Trabalho cobra, joga metas e culpa. Um psicólogo ou psicóloga chega para caminhar junto, sem carregar nada por você. No fim: **bem-estar não é linha de chegada, e ninguém chega sozinho.**

Antes de começar, você escolhe quem vai ser (cor, gênero, orientação, classe, deficiência, filhos). A dificuldade muda conforme as escolhas, porque o caminho não é igual para todo mundo.

## Controles

- **Teclado:** setas ou WASD para andar, espaço para pular, E para largar uma carga, M para o som
- **Celular:** arraste na tela para andar, toque rápido ou PULAR para pular, LARGAR para soltar uma carga
- **Controle de videogame:** analógico para andar, A para pular, B para largar
