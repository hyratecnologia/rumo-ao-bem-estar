# Rumo à Saúde Mental

Joguinho em pixel art feito para a **Semana da Psicologia**, sobre saúde mental e cobranças.

**Jogar:** https://hyratecnologia.com/rumo-a-saude-mental/ (também em https://hyratecnologia.github.io/rumo-ao-bem-estar/)

## A ideia

Você segue uma avenida rumo à saúde mental. No caminho caem cargas: algumas dá para largar (curtidas, padrão de beleza, "ter mais"), outras não saem (boleto, trabalho, faculdade, doença). As coisas que você ama também caem, e a pressão vai tirando elas de você. Pessoas de máscara de felicidade passam e "chegam lá". O Mercado de Trabalho cobra, joga metas e culpa. Um psicólogo ou psicóloga chega para caminhar junto, sem carregar nada por você. No fim: **saúde mental não é linha de chegada, e ninguém caminha sozinho.**

Antes de começar, você escolhe quem vai ser (cor, gênero, orientação, classe, deficiência), e a dificuldade muda conforme as escolhas. Mas na hora de nascer vem o sorteio: **você não escolhe.** As barreiras sociais (racismo, machismo, LGBTfobia, pobreza, capacitismo) são muros que ocupam a rua inteira e não dá para pular nem desviar deles, porque não dependem de quem passa.

É um joguinho: as situações são representações simplificadas e gamificadas, feitas para abrir conversa, sem a intenção de medir ou diminuir a dor de ninguém.

## Controles

- **Teclado:** setas ou WASD para andar, espaço para pular, E para largar uma carga, M para o som
- **Celular:** arraste na tela para andar, toque rápido ou PULAR para pular, LARGAR para soltar uma carga
- **Controle de videogame:** analógico para andar, A para pular, B para largar
